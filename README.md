# Personal Portfolio | Haneen

A modern, responsive multi-page personal portfolio built as a final project for the **NASS Academy IT Department (2025-2026)**. This project demonstrates frontend development skills including responsive design, theme persistence, and interactive UI components.

## 🚀 Live Demo

**https://whokilledevv.github.io/MyPortfolio/** 


## ✨ Features

* 
**Responsive Navigation:** A custom-built navigation bar that adapts to desktop, tablet, and mobile views.


* 
**Mobile Menu Toggle:** A sliding overlay menu for seamless navigation on smaller screens.


* 
**Dark/Light Mode:** A theme switcher that persists across sessions using `localStorage`.


* 
**Form Validation:** Built-in JavaScript validation for the contact portal to ensure data integrity before submission.


* **Entrance Animations:** Smooth "fade-in-up" animations to enhance user experience during page transitions.

## 🛠️ Technologies Used

* 
**HTML5:** Semantic structure for accessibility and SEO.


* 
**Tailwind CSS:** Utility-first framework for modern, responsive styling.


* 
**JavaScript (ES6+):** Logic for interactivity, theme switching, and form handling.


* **Google Fonts:** Playfair Display (Serif) and Inter (Sans-serif) for premium typography.

## 📁 Project Structure

```text
├── index.html       # Homepage (Introduction & CTA)
├── About.html       # Bio, Education, and Experience
├── Projects.html    # Gallery of featured work
├── Contact.html     # Validated contact form and social links
├── assets/          # Images and icons
└── css/             # Custom styles (if applicable)

```



## ⚙️ Setup Instructions

To run this project locally:

1. **Clone the repository:**
```bash
git clone https://github.com/whokilledevv/MyPortfolio

```


2. **Navigate to the directory:**
```bash
cd MyPortfolio

```


3. **Open the project:**
Simply open `index.html` in any modern web browser.
